Stock Guide

Hide, restore, add, and publish fabric catalog changes.

Open Catalog Download PDF

Daily Rule

Active fabrics live in the images/ folder. Out-of-stock fabrics live in archive/out-of-stock/. The website, PDF, thumbnails, and search data are rebuilt from the active images/ folder.

For normal office work, hide fabrics with the script. Do not delete the photo unless you are sure it will never be needed again.

⚡ Quick Method — deploy.sh (Recommended)

One command does everything automatically — archive/restore, rebuild, commit, push. No questions asked. Website goes live in ~2 minutes.

1. Open Terminal & Go to Project

cd /Users/sbtailor/StudioProjects/aa/semwal-bespoke-fabrics

2. Run One Command

Mark out of stock (1 or more):

./deploy.sh I-440
./deploy.sh I-440 I-306 PI-531

Bring fabric back:

./deploy.sh restore I-440

Set metres remaining:

./deploy.sh meters I-217 4

Add new fabric (after putting photo in images/):

./deploy.sh

3. Done! ✅

That's it. No y to type, no extra commands. The script shows you coloured progress messages so you know exactly what it's doing. Website is live in ~2 minutes.

💡 Type ./deploy.sh help to see all commands anytime.

🔧 Normal Method (Step-by-Step)

Use this if you want manual control over each step, or if deploy.sh has any issue.

Hide Out-Of-Stock Fabric

1. Open Terminal In This Project

cd /Users/sbtailor/StudioProjects/aa/semwal-bespoke-fabrics

2. Run The Hide Command

./mark-out-of-stock.sh I-440

For many fabrics, run one line per fabric:

./mark-out-of-stock.sh I-358
./mark-out-of-stock.sh I-366

3. Approve Publish

When Terminal asks this question, type y and press Enter.

Commit and push these catalog changes now? [y/N]

Bring Fabric Back

./restore-fabric.sh I-440

Then type y when asked to publish.

Set Metres Remaining (Low Stock Warning)

1. Set Metres

./set-meters.sh I-440 4     # under 5 mtrs → red bar + Low Stock badge
./set-meters.sh I-102 7     # 5–10 mtrs → yellow bar
./set-meters.sh I-135 12    # 10+ mtrs → green bar
./set-meters.sh I-21 0      # remove the bar (restocked)

2. Rebuild & Publish

./update-catalog.sh

Type y when it asks to commit and push.

Metre bar colours: 🔴 Red + "Low Stock" = under 5 mtrs  ·  🟡 Yellow = 5–10 mtrs  ·  🟢 Green = 10+ mtrs

Add New Fabric

1. Add Photo

Put the new fabric photo in images/. Name it with the fabric code, for example I-463.jpg or PI-532.jpg.

2. Rebuild & Publish

./update-catalog.sh

Type y when asked.

Check Your Work

  • Search the code on the website. Hidden fabrics should show no result.
  • Open the PDF and search the code with Cmd+F or Ctrl+F.
  • If the online website looks old, hard refresh with Cmd+Shift+R on Mac or Ctrl+Shift+R on Windows.
  • Use the "Less than 5 Mtrs" filter under Advanced Filters to see all low-stock fabrics at once.
